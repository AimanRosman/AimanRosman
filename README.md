## Selected projects

These public prototypes and tools show the problems I like working on.
Their READMEs cover setup, architecture, and current limitations.

| Project | What it explores |
| :--- | :--- |
| **[Parking occupancy](https://github.com/AimanRosman/AI-Parking-Slot-Monitoring)**<br><sub>Python, OpenCV, YOLO</sub> | Car detection, polygon-based parking occupancy, and CSV analytics in a desktop vision workflow. |
| **[ESP32 waste sorter](https://github.com/AimanRosman/AI-ESP32-Recycle-Bin-Sorter)**<br><sub>Arduino C++, ESP32, Edge Impulse</sub> | Camera inference and a networked actuator controller coordinating stepper and servo sorting. |
| **[K230 landmark monitoring](https://github.com/AimanRosman/CanMV-K230-Drowsiness-Detection)**<br><sub>Python, CanMV K230</sub> | Facial-landmark geometry for visualizing eye closure and yawning on an edge device. |
| **[Gate and attendance](https://github.com/AimanRosman/AI-Gate-Control-and-Attendance-System)**<br><sub>Python, ESP8266, Google APIs</sub> | Face recognition, RFID relay control, audio feedback, and Google Sheets attendance integration. |
| **[JARVIS voice assistant](https://github.com/AimanRosman/Jarvis-AI-Assistant)**<br><sub>Python, PySide6, Gemini Live, Three.js</sub> | A desktop assistant combining voice input, multimodal sessions, speech synthesis, and an avatar. |

## Tools I use

**Vision and AI** &nbsp; Python, OpenCV, Ultralytics YOLO, face_recognition, Gemini Live

**Embedded systems** &nbsp; Arduino C++, ESP32, ESP8266, CanMV K230, Raspberry Pi Pico

**Applications and data** &nbsp; PySide6, JavaScript, Three.js, MySQL, SQLite

**Development** &nbsp; Git, GitHub Actions
