<summary>About this profile</summary>

The terminal layout is inspired by [Andrew6rant's profile](https://github.com/Andrew6rant/Andrew6rant). The illustration and generator here are original and personalized for my work.

The card refreshes daily through [GitHub Actions](.github/workflows/profile-card.yml), using the built-in workflow token. It queries only public user and public owner-repository metadata. Public repository counts include forks; stars count original public repositories only. Counts are a snapshot, not a measure of project quality.

The generator uses Python 3.10+ and its standard library. To regenerate from live public metadata:

```bash
python scripts/generate_profile.py
```

To reproduce the saved card without network access:

```bash
python scripts/generate_profile.py --snapshot assets/profile-data.json
```

The exact public values and UTC update date are recorded in [profile-data.json](assets/profile-data.json). Only the six defined aggregate fields are saved. Private repository data, commit history, and company information are not included.
